# Text_to_voice-convertor
🎤 Text-to-Voice Converter A simple and responsive Text-to-Voice Converter built using HTML, CSS, and JavaScript. This web application allows users to enter any text and convert it into speech using the Web Speech API, providing an accessible and interactive text-to-speech experience.

🧰 Technologies Used HTML5 – Structure and content CSS3 – Styling and responsive design JavaScript (ES6) – Functionality and text-to-speech converion

🚀 Features 
✅ Convert text input into clear synthesized speech 
✅ Select from available system voices 
✅ Control speech rate and pitch 
✅ Responsive design (works on desktop and mobile) 
✅ Intuitive user interface
